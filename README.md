This is a Rock Paper Scissors game coded using plain JavaScript and is part of The Odin Project’s Foundations curriculum. Here, the player has to make a choice between Rock, Paper, and Scissors, whereas the choice for the computer is made randomly by the use of Math.random(). In each round, the outcome is calculated using both the choices made in each round and continues for five rounds, after which the overall winner is declared based on the number of rounds won. In this assignment, the aim is to learn about basic JavaScript concepts such as functions, conditions (if/else and switch), loops, arrays, and parameter passing between functions.
